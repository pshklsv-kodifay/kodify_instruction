# Как развернуть статический сайт с помощью GitHub Pages

### Пошаговая инструкция

**Основной принцип:**
Основной принцип заключается в использовании специальной ветки, по умолчанию названной `gh-pages`, для размещения файлов вашего веб-сайта. GitHub автоматически обнаруживает эту ветку и использует ее для публикации вашего сайта. Этот метод эффективен, поскольку он позволяет отделить исходный код (если вы решите вести разработку в ветке `main` или `master`) от готового к развертыванию кода в ветке `gh-pages`. Для простых статических сайтов, где исходный код и есть результат, вы просто отправляете одно и то же содержимое в обе ветки.

1.  **Инициализация Git-репозитория (если вы еще этого не сделали):**
    *   Откройте ваш терминал или командную строку.
    *   Перейдите в корневой каталог вашего проекта.
    *   Инициализируйте новый Git-репозиторий:
        ```bash
        git init
        ```

2.  **Фиксация всех необходимых файлов:**
    *   Добавьте все файлы проекта в область подготовленных файлов:
        ```bash
        git add .
        ```
    *   **Важно:** Проверьте ваш файл `.gitignore`. Убедитесь, что вы **не** игнорируете какие-либо важные библиотеки или ресурсы, которые понадобятся для работы сайта.
    *   Зафиксируйте ваши изменения с описательным сообщением:
        ```bash
        git commit -m "Initial commit for deployment"
        ```

3.  **Создание репозитория на GitHub:**
    *   Перейдите на [github.com](https://github.com) и создайте новый пустой репозиторий. Для этого руководства мы будем использовать имя `kodify_instruction`.

4.  **Привязка локального и удаленного репозиториев:**
    *   Добавьте репозиторий GitHub в качестве удаленного с именем `origin`:
        ```bash
        git remote add origin https://github.com/pshklsv-kodifay/kodify_instruction.git
        ```

5.  **Создание и отправка ветки `gh-pages`:**
    *   Создайте новую ветку с именем `gh-pages` на основе вашей текущей ветки (`main` или `master`):
        ```bash
        git checkout -b gh-pages
        ```
    *   Отправьте новую ветку `gh-pages` на GitHub:
        ```bash
        git push -u origin gh-pages
        ```

6.  **Включение GitHub Pages для вашего репозитория:**
    *   Перейдите в ваш репозиторий на GitHub: `https://github.com/pshklsv-kodifay/kodify_instruction`.
    *   Нажмите на вкладку **"Settings"** (Настройки).
    *   В левом боковом меню нажмите на **"Pages"**.
    *   В разделе **"Build and deployment"**:
        *   В качестве **"Source"** выберите "Deploy from a branch".
        *   В разделе **"Branch"** выберите `gh-pages`.
        *   Нажмите кнопку **"Save"**.

7.  **Проверка и доступ к сайту:**
    *   После сохранения настроек GitHub Pages может потребоваться несколько минут для развертывания вашего сайта.
    *   Обновите страницу настроек **"Pages"**, и GitHub отобразит URL-адрес, по которому ваш сайт будет доступен. Обычно он имеет следующий формат: `https://<ваш-username>.github.io/<имя-вашего-репозитория>/`.
    *   Для этого проекта URL должен быть: `https://pshklsv-kodifay.github.io/kodify_instruction/`.

Теперь ваш статический сайт должен быть доступен на GitHub Pages!
