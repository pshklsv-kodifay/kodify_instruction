Инструкция по установке Kodu Game Lab

Kodu Game Lab — бесплатная программа для создания 3D-игр. В ней персонажи программируются цветными блоками, а не текстом кода. Программа работает на Windows, ключ активации не нужен.

Kodu ставится только на Windows: 11, 10, 8 или 7. На macOS и Android официальной версии нет. Нужна видеокарта с поддержкой DirectX 9.0c. Библиотека XNA 4.0 уже входит в файл KoduSetup.EXE, отдельно её скачивать не нужно.

Шаг 1. Откройте страницу загрузки

Откройте браузер и перейдите на официальную страницу загрузок Kodu:

https://www.kodugamelab.com/downloads/

Сверху будет баннер Kodu Game Lab. Ниже на странице — ссылки на установщик.

Шаг 2. Скачайте KoduSetup.EXE

Пролистайте страницу до заголовка Latest Version : 1.6.18.0. Нажмите ссылку KoduSetup.EXE. Браузер начнёт скачивать установочный файл.

Скачивайте именно KoduSetup.EXE. Файл KoduSetup.MSI нужен системным администраторам для установки сразу на много компьютеров. Для дома и занятий достаточно EXE: в нём уже есть всё необходимое, включая XNA 4.0.

Шаг 3. Найдите файл в папке «Загрузки»

Откройте папку Загрузки. В ней появится файл KoduSetup_1.6.18.0.exe с иконкой компьютера и диска. Дважды щёлкните по нему, чтобы запустить установку.

Шаг 4. Установите программу

Windows спросит, разрешаете ли вы приложению вносить изменения на компьютере. Нажмите «Да».

Первым появится окно «Выберите язык установки». Оставьте Русский и нажмите ОК.

Следующее окно — лицензионное соглашение. Оставьте точку у пункта «Я принимаю условия соглашения» и нажмите «Далее».

Дальше мастер спросит папку установки. Оставьте путь C:\Program Files (x86)\Microsoft Research\Kodu Game Lab и нажмите «Далее».

Затем появится окно «Выберите дополнительные задачи». Оставьте галочки включёнными: так на рабочем столе появится ярлык Kodu. Нажмите «Далее».

После этого нажмите «Установить». Дождитесь копирования файлов и в конце нажмите «Готово».

Если Windows SmartScreen напишет, что приложение неизвестно, нажмите «Подробнее», затем «Выполнить в любом случае». Это официальный установщик с сайта kodugamelab.com.

Шаг 5. Запустите Kodu

Откройте меню Пуск и начните печатать Kodu. В списке появится Kodu Game Lab — запустите его.

Сначала на экране появится персонаж Kodu: программа загружается, нужно подождать несколько секунд.

Шаг 6. Войдите как Guest

Откроется окно Sign In. В поле Creator уже стоит имя Guest, в поле Pin — код 0000. Это гостевой вход, регистрироваться не нужно. Нажмите OK.

После входа откроется главное меню. Справа будет персонаж Kodu, слева — новости, по центру список команд: NEW WORLD (новый мир), ЗАГРУЗИТЬ МИР, ПАРАМЕТРЫ и другие. Установка закончена, можно начинать занятие.

Язык меню меняется в пункте ПАРАМЕТРЫ (Options): найдите плитку Language и выберите русский. После смены языка программу нужно закрыть и открыть снова.
